20<a id="learning-objectives"></a>
21## 学习目标
22
23完成本路线后，学员能够：
24
251. 安装或验证基于 Docker 的 OpenMES 部署，并完成首次运行设置
262. 为工厂建模：工厂、事业部、产线、工位
273. 创建用户、分配角色，并将操作员/主管映射到产线
284. 配置产品类型与工艺模板
295. 创建并导入工单；说明 pending（待处理） → accepted（已接单）的流程
306. 调整影响车间的系统设置（生产周期、超产、顺序工序）
317. 在需要集成时启用或安装模块并管理 API 令牌
328. 具备基本的维护意识（审计日志、更新、示例数据）

45<a id="session-outline"></a>
46## 课程大纲
47
48### 1. 安装与初始步骤（30–45 分钟）
49
50- 前置条件（Docker、Git）
51- `docker-compose up -d` 与 Web 安装器（站点、数据库、管理员账号）
52- 生产环境加固要点（`APP_DEBUG`、HTTPS、保护 `.env`）
53- 安装后检查清单：产线、用户、分配、产品、模板、工单
54
55**材料：** [管理员指南 → 安装](../admin-guide.md#installation)、[安装后的初始步骤](../admin-guide.md#first-steps-after-installation)
56
57### 2. 用户与角色（20–30 分钟）
58
59- 角色：Admin（管理员）、Supervisor（主管）、Operator（操作员）
60- 创建用户；为操作员/主管分配产线
61- 密码重置策略（不支持自助 —— 由管理员/主管处理）
62
63**材料：** [用户管理](../admin-guide.md#user-management)
64
65### 3. 生产结构（30–40 分钟）
66
67- 工厂 → 事业部 → 产线 → 工位 层级
68- 创建一条活动产线；添加工位
69- 为什么操作员只能看到已分配的产线
70
71**材料：** [生产结构](../admin-guide.md#production-structure)
72
73### 4. 产品与工艺模板（30–40 分钟）
74
75- 产品类型作为分类
76- 工艺模板：有序工序、可选的必需角色
77- 将模板关联到产品类型，以便创建工单
78
79**材料：** [产品配置](../admin-guide.md#product-configuration)
80
81### 5. 工单与主管交接（30–40 分钟）
82
83- 手动创建工单（编号、数量、产线、类型、模板、交期、优先级）
84- CSV/Excel 导入：必填字段、策略、已保存的映射配置
85- pending 工单必须先由主管 **Accept（接单）**，操作员才能看到
86- 通过主管工作流了解暂停 / 恢复 / 拒单
87
88**材料：** [工单](../admin-guide.md#work-orders)、[主管指南 → 管理工单](../supervisor-guide.md#managing-work-orders)
89
90### 6. 系统设置与模块（30–40 分钟）
91
92- 生产周期、超产、顺序工序强制
93- 启用/禁用模块；在适用时从 ZIP 安装
94- 用于集成的 API 令牌
95- 班次、HR 基础、审计日志、更新概览
96
97**材料：** [系统设置](../admin-guide.md#system-settings)、[模块](../admin-guide.md#modules)、[API 令牌](../admin-guide.md#api-tokens)、[审计日志](../admin-guide.md#audit-logs)、[更新](../admin-guide.md#updates)
98
99### 7. 次日运维（20 分钟）
100
101- 监控：主管仪表盘、问题、报表（供管理员了解）
102- 仅当现场使用信号采集时才涉及机器/MQTT 连通性 —— 指向参考文档，除非在范围内否则不深入
103
104**材料：** [主管指南](../supervisor-guide.md)，可选[机器连通性](../machine-connectivity.md)、[MQTT 连通性](../mqtt-connectivity.md)
105

121<a id="hands-on-exercises"></a>
122## 动手练习
123
1241. **全新环境检查清单** —— 从一个干净（或重置）的实验环境出发，完成安装后步骤，直到建立一条活动产线与两个用户（操作员 + 主管）。
1252. **构建模板** —— 创建一个产品类型与一个 3–5 步的工艺模板；将模板分配给该类型。
1263. **工单路径** —— 创建一个 pending 工单，以主管身份接受它（Accept），再以操作员身份完成一个批次。
1274. **导入** —— 用仅插入策略导入一个小 CSV；确认重复导入时跳过重复项。
1285. **设置开关** —— 修改顺序工序或超产设置，并向学员演示其在车间的影响。
1296. **模块认知** —— 列出已启用的模块，并描述如何在非生产实验环境中启用/禁用一个模块。
