20<a id="learning-objectives"></a>
21## 学习目标
22
23完成本路线后，学员能够：
24
251. 描述技术栈与仓库结构（Laravel 后端、Blade/Alpine/Livewire UI、modules 目录）
262. 运行本地开发环境，并知道测试与格式化位于何处
273. 解释 RBAC 角色，以及 operator（操作员）/ supervisor（主管）/ admin（管理员）界面位于何处
284. 搭建或勾勒一个模块（`module.json`、服务提供者、路由、迁移）
295. 针对钩子/事件系统注册事件监听器，而无需改动核心控制器
306. 使用 REST API 文档进行集成（认证、常用资源）
317. 遵循贡献约定（分支、约定式提交、PR 预期）

36## 前置条件

44<a id="session-outline"></a>
45## 课程大纲
46
47### 1. 架构概览（30–40 分钟）
48
49- 技术栈表：Laravel 12、PHP 8.3、PostgreSQL、Sanctum、Spatie Permission、Vite、Docker
50- 仓库地图：`backend/`、`modules/`、`docs/`、compose 文件
51- 请求路径：web（Blade/Livewire）vs `api/v1`
52- 高层介绍租户 / 角色模型
53
54**材料：** [技术文档 → 技术栈](../development.md#tech-stack)、[仓库结构](../development.md#repository-structure)、[架构概览](../development.md#architecture-overview)
55
56### 2. 本地开发环境搭建（30–45 分钟）
57
58- 克隆、compose、安装器或 `.env` 配置
59- `composer install`、前端资源、运行应用
60- 功能/单元测试位于何处；`php artisan test`
61- 代码风格（`pint`）与[贡献](../CONTRIBUTING.md)预期
62
63**材料：** [本地开发环境搭建](../development.md#local-development-setup)、[测试](../development.md#testing)、[代码风格](../development.md#code-style)、[贡献](../CONTRIBUTING.md)
64
65### 3. 模块系统（45–60 分钟）
66
67- 模块目录结构与 `module.json`
68- 服务提供者注册与侧边栏导航
69- 模块迁移与安全地扩展核心模型
70- 针对现场专属行为，优先用模块而非 fork 核心
71
72**材料：** [模块系统](../development.md#module-system)、[HOOKS.md → 创建模块](../../HOOKS.md#creating-a-module)
73
74### 4. 钩子与事件（45–60 分钟）
75
76- 以 Laravel 事件作为扩展点
77- 在模块服务提供者中注册监听器
78- 概览主要钩子分组：工单、批次、批次工序、用户、产线、工艺模板、CSV 导入
79- 最佳实践：让监听器保持聚焦；避免破坏事务路径
80
81**材料：** [钩子系统](../development.md#hook-system)、[HOOKS.md](../../HOOKS.md)（可用钩子与示例）
82
83### 5. API 与集成（30–45 分钟）
84
85- API 客户端使用 Sanctum 会话 vs 令牌
86- 浏览 [API 文档](../API_DOCUMENTATION.md) 了解常用资源
87- 由管理员管理的 API 令牌（参见管理员路线）用于外部系统
88- 可选：如果构建协议适配器，概述机器信号管道
89
90**材料：** [API 开发](../development.md#api-development)、[API 文档](../API_DOCUMENTATION.md)，可选[机器连通性](../machine-connectivity.md)
91
92### 6. 贡献流程（15–20 分钟）
93
94- Fork，从 `main` 切分支，保持 PR 聚焦
95- 约定式提交（`feat`、`fix`、`docs`、……）
96- 为用户可见行为补充测试与文档
97- 只有在贡献者能跑通测试套件之后，才让他们认领文档/代码 issue
98
99**材料：** [贡献 → 提交改动](../CONTRIBUTING.md#submitting-changes)、[提交信息约定](../CONTRIBUTING.md#commit-message-convention)
100

117<a id="hands-on-exercises"></a>
118## 动手练习
119
1201. **梳理代码** —— 沿着 UI 上的一个工单接单操作，定位控制器/服务，并指出一个相关事件（若存在）。
1212. **开发启动** —— 在本地启动整套环境，并成功运行一个聚焦的测试子集。
1223. **模块骨架** —— 创建一个（或勾勒出）带 `module.json` 与服务提供者的模块，注册一个空操作监听器。
1234. **钩子监听器** —— 监听工单或批次完成事件并写入日志（仅限实验环境）。
1245. **API 读取** —— 用令牌或会话调用一个有文档的读取端点，并展示其 JSON 结构。
1256. **文档 PR 练习（可选）** —— 开一个只改文档的分支修正一处拼写错误，演练贡献流程。
