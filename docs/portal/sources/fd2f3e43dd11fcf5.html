1# 使用情况上报（遥测）
2
3OpenMES 会就**自身**进行上报，以便我们了解哪些功能被使用、现场有哪些环境、哪些
4版本会出问题——而不必等着有人给我们发邮件。
5
6它默认开启，点一下即可关闭。
7
8## 边界
9
10> OpenMES 发送的是**关于软件本身**的信息——版本、开启了哪些功能、粗略的量级区间，
11> 以及错误发生的位置（类、文件和行号）。它绝不发送你录入 OpenMES 的任何内容：
12> 没有物料或产品编码，没有批次号，没有订单数据，没有配方，没有个人数据，
13> 也没有错误消息文本。
14
15| 发送 | 从不发送 |
16|---|---|
17| OpenMES、PHP、PostgreSQL 和 OS 版本 | 物料、产品、批次和订单的编码或名称 |
18| 开启了哪些模块和模式 | 订单内容、配方、BOM、已生产数量 |
19| **量级区间**（`"50-199"`），从不是精确计数 | 用户名、姓名、电子邮件地址、PIN、IP 地址 |
20| 异常类 + 文件 + 行号 + 计数区间 | **错误消息文本**和堆栈追踪 |
21| 一个随机的安装 UUID | 公司或客户名称、任何在字段中录入的内容 |
22
23这由测试来强制保证，而不是靠良好意愿。`TelemetryPayloadTest` 会播种一整个工厂规
24模的逼真数据，构建真实载荷，只要其中出现任何一个来自数据库的值就失败。文档会过
25时；那个测试不会。
26
27### 为什么错误消息被完全排除
28
29在本系统中无法可靠地对它们做脱敏。`InsufficientStockException` 会产生：
30
31```
32Insufficient stock for material "Bolt M8" (BOLT-M8-001): required 5.0000 pcs, available 2.0000 pcs.
33```
34
35去掉引号和长的数字串，`BOLT-M8-001` 依然还在——这个编码会向读者透露工厂生产什么。
36`QueryException` 更糟：它的消息把 SQL 连同绑定值一起带上。与其过滤，不如让缓冲区
37根本不读取消息，这样别人明年写的异常从结构上就是安全的。
38
39## 关闭它
40
41以下任意一条即可：
42
431. **Settings → System → Usage reporting**——那个开关。
442. `.env` 中的 **`OPENMES_TELEMETRY=false`**——在数据库之前读取，因此在内网隔离的
45 机器上、以及在从未启动过的打包版本中都能生效。
463. 在你的防火墙上**封禁该主机**。不会出问题；见下面的「无互联网」。
47
48在 `local` 和 `testing` 环境、安装期间，以及公共 demo 服务器上，上报也会自动关闭。
49
50## 查看究竟发送了什么
51
52两种方式，都会展示由负责发送的同一段代码构建的真实载荷：
53
54```bash
55php artisan telemetry:send --dry-run
56```
57
58或者 **Settings → System → Usage reporting → Show exactly what is sent**。
59
60两者在上报关闭时同样可用——问这个问题的人往往刚刚把它关掉。

88## 发送到何处、多久一次
89
90`POST https://getopenmes.com/telemetry.php`，每天一次，来自一个队列任务。
91
92小时数由安装自身的 id 推导而来、而非固定，因此各安装不会都在同一分钟到达。
93
94## 没有互联网？什么都不会坏
95
96出站防火墙关闭对工厂来说是常态，不是故障。连不上我们的安装，其行为与能连上的完
97全一样：
98
99- 界面中无错误、无警告，对任何页面都没有影响；
100- 失败绝不会被重试并进入 `failed_jobs`；
101- 一次运行中只有**第一个**失败会被记录，级别为 `debug`——离线一年也不会塞满日志；
102- 3 次失败后尝试频率退避为每周一次，10 次后为每月一次。
103
104## 安装 ID
105
106一个位于 `storage/telemetry-id` 的随机 UUID，首次使用时创建。它是随机的，
107而不是由你的主机名或 URL 推导而来，因此它不会透露关于你的任何信息，你也可以轮换它。
108**Settings → Reset installation ID** 会删除它——在把一台生产机克隆到预发环境后很有
109用，否则两份副本会被上报为同一个安装。
110
111> `storage/` 必须是持久卷。丢弃它的容器每次重启都会生成一个新的 id。它本来就必须
112> 为 `storage/installed` 持久化。
113
114## 数据保护
115
116载荷中不含个人数据。到达 getopenmes.com 的源 IP 地址在欧盟法律下属于个人数据；
117它不会被保留。
118
119上报未经认证，因此可被伪造，所以安装数量只是估计值，而非确凿事实。
