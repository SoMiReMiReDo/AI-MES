01↗

项目全景与阅读地图

OpenMES 将生产计划转成可执行工序，再把实际产量、物料、质量与设备记录回收到同一业务链。

02↗

领域对象与数据归属

先区分配置、计划、执行和事实数据，才能理解为什么同一工艺会在多个对象中出现。

03↗

生产主链与事务边界

从一次完成工序请求追到产量回写，分清入口授权、领域约束与数据库提交。

04↗

两种流转与数量账本

whole_batch 控制整批顺序，transfer 让工序按已转出的数量重叠执行。两者的完工与计产时点不同。

05↗

物料、质量与仓储闭环

生产会触发分配、耗用和检验；仓库草稿与正式库存过账属于另外的业务阶段。

06↗

设备信号与 ERP 集成

外部系统只提供输入；OpenMES 仍要决定读数属于谁、是否新鲜、是否可计入生产。

07↗

前端入口与实时读模型

React 页面负责呈现与交互，Laravel 写业务数据，实时集合让多个页面看到提交后的结果。

08↗

权限、租户与扩展模块

界面是否可见、用户是否有权操作、数据是否属于当前租户，是三层不同约束。

09↗

排程、绩效与追溯旁路

这些子系统围绕生产主链提供计划、解释和追查能力；应按业务问题选择入口。

10↗

开发、验证与问题定位

用现有测试约束修改范围；区分文档站验证、业务测试和生产环境验证。
