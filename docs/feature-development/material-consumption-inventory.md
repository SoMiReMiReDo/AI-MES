# F8-`MaterialConsumptionInventory` 硅片来料来源追溯

2026-11-18 用户确认本轮交付 F08-01。范围为硅片物料、来源和来料批登记，建批时选取来源，以及来料批与晶圆的双向追溯。F08-02～05 和 F6-06 继续按需，账本主从留待这些能力启用前确认。功能依据见 [Fab 全功能清单](../development-process/07-fab-function-catalog.md#f8-materialconsumptioninventory-物料耗用与库存)。

## 数据与责任

| 对象 | F08-01 规则 |
| --- | --- |
| Material | 复用物料主数据，归入系统硅片类别；代码全局唯一，固定单位片（PCS）、按批追踪。 |
| MaterialSource | 复用物料来源，新增本厂手工来源模式；按厂区、物料、来源代码唯一，记录人工提供的来源代码和名称。集成模式继续使用既有 IntegrationConfig 外键。 |
| MaterialLot | 必须引用本厂手工来源和对应物料；MES 来料批号在同物料内唯一，另保存独立的供应方批号和可选有效日期。用本厂专用登记仓解析范围，状态为 Registered，收货及可用数量为零。 |
| Wafer | 建片沿用 OriginMaterialLotId，并可保存逐片供应方片号。拆合批只调整成员关系，晶圆来源沿永久身份保留。 |

登记用于演示和来源追溯。可用库存、来料检验结论、实际领用与消耗量需由对应后续流程形成。登记数据提供创建与查询入口；历史来源更正继续留在 GAP-11。

## 架构与协作

- 继续采用模块化单体。Application 定义请求契约，Infrastructure 的物料模块负责登记及查询，API 沿用认证、防伪、授权和 ProblemDetails，WebUI 增加「硅片来料」入口。
- 物料模块和 F4 共用 MesDbContext。写命令使用既有事务、全局写锁、幂等回执、审计和业务事件。所有读取先限定厂区，再分页或统计。
- F4 保留原建批契约。WebUI 支持同一来料批应用到本次片集，并保存每片的来源 FK。来源允许为空，显示「来源未登记」。既有引用仍按既有兼容路径校验和显示。
- 对本模块登记的来源，建片和首次投放都校验厂区、物料/来源一致性、启用状态、批次状态、有效期和当前冻结。有效日期按厂区当地日期判断，包含截止日。手工硅片登记在 F7 上机耗材入口隔离。
- 晶圆详情可展示经过范围校验的来料批号与物料，并按权限打开来料详情。反查按晶圆永久来源关联，返回当前晶圆状态及可授权的当前生产批链接，历史成员和加工沿原晶圆履历读取。
- 物料登记使用 `materials.wafer-sources.manage`；目录和详情使用 `materials.wafer-sources.read`。建批选项对已有 `production.lots.create` 的用户开放精简列表，物料批反查晶圆同时要求 `production.wafers.read`。既有管理员随迁移获得新权限，其他既有角色沿用原授权。

接口和验证场景见 [F08-01 接口与验收](material-consumption-inventory-api-and-acceptance.md)。

## 实现与本地验收

- 第 10 条迁移增加手工来源的厂区外键及唯一约束。开发库已先备份再升级；运行角色通过 `python3 scripts/app.py provision-materials` 增量获得登记权限。字段字典、幂等 DDL 和 OpenAPI 类型已同步。
- 17 项数据库测试、91 项 API 测试和 Chrome F1～F8-01 全流程已通过。F08-01 覆盖建批投放、拆批后的反查、幂等重放、跨厂与权限隔离、冻结后拒绝，以及对库存流水和 F7 耗材入口的隔离。
- 开发环境从侧栏「硅片来料」登记物料、来源和来料批。「生产管理」建批时选填来料批，从晶圆履历或来料批详情打开追溯。
