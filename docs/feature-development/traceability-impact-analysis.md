## 查询流程

在「生产运营 → 生产追溯」选择工单、Lot、Wafer、载具或设备，输入完整或部分编号，打开匹配对象并查看当前状态。履历按事件发生时间倒序展示，可按记录类别及时间段筛选、分页。履历按厂区时区显示，时间筛选按本机时区输入并转换为 UTC。对象和原始记录可通过链接打开，生产管理中的批次、晶圆和载具详情也可直接进入。

追溯首页显示最近查看的对象和最近查询的编号，各最多保留 6 条。点击历史可重开履历或重新执行查询。记录按用户与厂区保存在当前浏览器标签页，可手动清空，退出或会话失效时清除。

| 起点 | 履历依据 | 下钻 |
| --- | --- | --- |
| 工单 | 工单创建、下达快照和完成记录，按工单归属展开本厂批次及相关生产、质量事实 | 批次和逐片记录 |
| Lot | 创建、关闭、逐片归属、实际工序到访、Run、质量记录；载具装卸按动作时刻的归属关联 | 本片、来源批和目标批 |
| Wafer | 历史归属、首次投放、终点完成、实际 Run 参与片、装卸、量测及处置 | 当前/历史批次、载具、实际加工设备、有权访问的登记来料批 |
| 载具 | 移位、槽位装卸；加工关联按实际参与片在 Track-in 时的装载区间 | 历史装载晶圆及其生产履历 |
| 设备 | 有效状态区间、设备事件和使用该设备的实际 Run；量测按明确记录的量测设备或 Run 关联 | 历史 Lot、Wafer 及加工记录 |

## 事实与权限

- 事件关联按当时原始记录建立。装载和 Track-in 关联采用左闭右开。卸载按结束时点前的有效归属关联，覆盖处置同时卸载和关闭归属的场景。解除 Hold 与质量放行保留各自来源。晶圆视角的批级检验和 Hold 用发生时的 Lot 归属，明示批级记录。带 WaferId 的量测只归到对应片。报废用处置时 Lot 和实际处置片。
- 拆合批按晶圆展示来源和目标批。批次页可沿任一端继续正反向下钻，晶圆页按时间展示本片经过的全部边。工序到访以 StepExecution ID/VisitNo 区分。拆合批继承的等待到访一并展示，实际加工以已记录 Run 和参与片为准。
- 设备和 Recipe 取 ProcessRun 实际绑定，保留 Track-in/out 操作人和逐片结果。量测保留类型化原值、单位和判定。载具关联说明 Track-in 时已装载。
- 查询沿用部署厂区和原模块读取权限。定位及主页需相应对象读权限，履历类别需相应来源模块读权限，跨对象下钻另校验目标权限。授权和厂区过滤在计数、分页及按 ID 打开证据前执行。只有生产身份及来源关系可解析的记录才会进入对应查询。空结果表示查询范围内无已登记的匹配记录。缺少显式 Fab 的旧 Wafer 不纳入搜索；旧 Run 缺少参与片时可随 Lot/设备查到 Run。
- 复用现有 Application 入口与 MesDbContext，每次查询使用一致性快照。独立 `TraceabilityImpactAnalysis` 查询投影由 PostgreSQL 先筛选和分页，再批量补充可见对象和操作者。无新增生产事实、迁移或权限码。WebUI 和后续 Agent 可通过同一应用入口读取。

## 接口与验收

| GET /api/v1/traceability | 契约 |
| --- | --- |
| `/search?kind=lot&q=编号&page=1&pageSize=20` | 类型 `work-order/lot/wafer/carrier/equipment`。编号按字面值匹配，结果按编号、ID 排序。 |
| `/{kind}/{id}` | 当前状态、可查履历类别、关联对象、快照时间。 |
| `/{kind}/{id}/events?group=execution&from=…&to=…` | 类别可省略；时间采用带偏移的 ISO 8601，起始含、结束不含；先筛选再分页，按发生时间倒序、事件类型、原始记录 ID 排序。 |
| `/{kind}/{id}/events/{type}/{sourceId}` | 打开该对象履历中的确切原记录，返回记录标识、发生时间、来源字段及有权查看的关联；换到无关对象下查询返回 404。 |

分页默认 20，最大 100。无动作权限 403，找不到或不在对象范围内 404，查询参数无效 400。

验收重点覆盖五种编号定位、拆合批正反向、同站重试、实际 Run 绑定、装卸区间、量测/Hold/处置、源记录直达、分页与时间边界，以及越厂和无读权限时的列表与详情。
