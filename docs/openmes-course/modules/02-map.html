分别追建单、接收和建批

这三个动作可以从不同入口发起。想找两端共有的规则，先看动作在哪一层汇合。

1
建单

主管网页与 API 的建单入口共用 WorkOrderService，由它构建工单快照。

2
接收

主管网页进入 WorkOrderService::applyTransition。API 侧先从控制器的 transition 跟起。

3
建批

网页与 API 汇到同一个服务方法。它从已存快照生成工序，记录所用版本，并把符合条件的工序推进到就绪。
