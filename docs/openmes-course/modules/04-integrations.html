车间边界与外部系统

把车间边界想成几个交接窗口。领料和质检决定流程何时能往下走，仓储把完工接到企业系统，设备信号和实时看板分别负责采集和展示。

物料分配与质量放行

领料像先把原料留给指定批次，再登记实际用掉的量。BOM 上的时点决定系统在哪个环节处理对应物料。

1

开始
批次首次进入生产时分配
未指定时点的物料也在此处理

→
2

工序
步骤开工时检查
指定给该步骤的物料

→
3

结束
批次完工时处理结束时点的物料
并办理批次消耗

物料窗口

MaterialAllocationService 处理物料分配和消耗。开始时的分配归到首道步骤，方便批次追溯。

质量窗口

来料检验面向收到的物料。生产质检关注加工过程或产出，QualityTriggerService 参与触发，流程到达已配置的质量门槛时要等放行。

ERP 导入工单有独立入口

入站走 /api/v1/erp/work-orders/import。该入口使用 ERP 的 API key 和 scope，移动端使用自己的认证与权限。
