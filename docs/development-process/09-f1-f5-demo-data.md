## 推荐展示顺序

1. **F1**：查看 `DEMO-AREA` 下的产线和位置，再查看 `DEMO-WS-01`、`DEMO-TERM-01`；员工包含一条停用示例。角色页查看 `DEMO-操作员`、`DEMO-工艺工程师`、`DEMO-计划员`、`DEMO-只读访客` 的不同权限。账号均要求首登改密；访客账号保留停用状态。审计页可查真实建立/停用/发布等操作，其中该页面目前仅展示 F1 实体审计范围。
2. **F2**：产品选 `DEMO-P300`；路线 `DEMO-ROUTE-300` 为“清洗 → 薄膜沉积 → 光学量测”。路线版本 `1.0` 已发布，`2.0-DRAFT` 是复制草稿。清洗 Recipe 另有 `2.0-DRAFT` 和已废止 `0.9-DEMO`。编号页可预览/分配；`DEMO-AUTO-WO-0002` 是真实自动编号工单。
3. **F3**：打开 `DEMO-WO-MAIN` 的“执行概况”，查看计划、投放、在制和完工；再对照草稿、取消及 `DEMO-WO-CLOSED` 的关闭状态与下达快照。
4. **F4**：打开 `DEMO-LOT-MERGED`，展开建批、拆批和合批血缘，查看逐片来源；在晶圆履历中查看 `DEMO-GENE-*` 的装卸、换槽和当前归属；FOUP 页查看槽位及移位记录。
5. **F5**：“待加工派工”中有 `DEMO-LOT-WAIT`，已人工指派但未开工；“加工与历史”默认显示加工中的 Run，打开即可看到 `DEMO-LOT-RUNNING` 正在第 20 站、实际设备/Recipe、PDF、已保存膜厚与点检。切换加工状态筛选可看已完成和已中止记录；失败记录的 Run 已结束，但逐片结果含 Failed，批次仍等待处置。

## 已发现的展示限制

- **F4 批次详情仍将“完工片数”显示为“待执行模块接通”**：其查询也保留 `completedQty = null` 和旧集成提示。这是既有查询/UI 占位，不能用演示数据改写消除；本轮未修改应用代码。真实完工请查看 F3 工单“执行概况”、晶圆完成状态与 F5 逐片结果。
- 设备人工 Idle 和是否被 Run 占用是两个维度；加工中的 `DEMO-TOOL-02` 人工状态仍为 Idle，实际占用在设备详情/加工记录查看，不能据列表 Idle 推断可开工。
- F6 未接通，FAILED/ABORT 批次保留等待处置；不伪造 Hold、放行、返工、报废流程。未登记来料来源继续显示“来源未登记”。
