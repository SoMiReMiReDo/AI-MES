# MESagent 网站设置开发计划

2026-11-19｜首版开发与验收

首版包括站点外观、系统信息、厂区排程默认视图和左侧导航。用户确认采用原创齿轮 Logo，排程初始为周视图，厂区管理员可保存日／周默认值。只有具备全厂区授权和写权限的系统管理员可以修改实例级站点外观。

## 建议开发顺序

### 1. 站点外观与系统信息

- 在「组织与系统」增加「系统设置」，采用 MESagent 现有 WebUI 样式。站点外观包含站点名称、副标题、默认浅／深／跟随系统主题，提供预览和按页保存。名称和副标题用于登录页和应用品牌区，浏览器标题使用站点名称。默认值从现有界面初始化，个人已选的浏览器主题优先。
- 设计一枚轮廓清晰的原创齿轮 Logo，作为随应用交付的固定品牌资源，在登录页与左侧栏共用。折叠时收起品牌文字，保留图案。图案细节以小尺寸和浅深背景上的识别度为准。
- 系统信息显示当前厂区、厂区时区、会话空闲与最长时限，以及服务就绪状态和检查时间。厂区时区沿用现有 `Fab.Timezone`，后台的「今日」、历史趋势、班次和 OEE 已使用这一时区，改区需另定业务规则。会话策略读取当前生效值，健康状态复用 F12 探针的简明结果。
- 实例级外观用类型化配置存入 PostgreSQL。登录前只返回名称、副标题、默认主题。管理读写分别授权给 F1 权限，写入使用现有 Cookie、CSRF 和 ETag 约定。成功保存时同事务写入 F12 审计，记录操作者、前后值和请求追踪 ID。升级旧库使用现有站点默认值，运行账号增量授权。

### 2. 排程默认周视图

- 排程页按厂区保存的默认值打开，初始显示厂区当前周，按厂区时区的周一至周日划分。提供上周／下周／本周和日／周切换，点日期进入当日视图。
- 周视图按设备汇总展示各日班次可排时段和计划，复用现有按日期范围查询及 14 天查询上限。周视图可打开计划详情，精确拖拽沿用日视图。自动排程继续使用确认表单中的起止日期，初值沿用选中日期。实时刷新、实际班次、设备占用、Lot 计划和开工走 F10/F5 的现有链路。
- 如有工单整理需求，再增加工单按周／月分组作为列表视图。库存门禁、扫码标识规则、质量失败处置需由对应业务负责人确认适用范围、生效时间和历史数据处理。

### 3. 左侧栏搜索与横向折叠

- 现有菜单搜索位于工作台的快捷入口。侧栏增加随页面可用的「搜索导航」，与工作台快捷入口共用现有权限过滤后的菜单数据。按菜单显示名称匹配，完整名称优先，其次是前缀、包含和按原顺序的部分字匹配。例如「设备与资源」完整命中，「设备」和「设资」也能找到同一入口。回车打开首项，清空后恢复分组，空结果给出提示。
- 桌面可手动横向缩为 64 像素的图标栏，浏览器记住桌面折叠状态。保留齿轮 Logo、菜单图标、搜索和展开入口，图标提供名称提示及键盘焦点。折叠态点击搜索图标打开浮层，侧栏保持折叠。窄屏默认使用图标栏，展开时以浮层承载完整菜单。
- 页面布局让正文随左栏宽度伸缩，兼容未来右侧 Agent 会话区。右栏按需占位，折叠左栏可为正文和右栏腾出更多空间。桌面、窄屏与浅深主题共用同一套导航行为。

### 4. 配置迁移与运维入口

- 有部署迁移需求时，先规划带版本的站点／排程配置 JSON 导出。导入先校验版本、字段范围与厂区归属，展示差异，再由授权管理员确认应用。导出范围到站点与排程配置为止，账号、密钥和生产记录由各自运维流程管理。
- 演示数据安装和备份恢复继续由 F14 命令执行。恢复以独立实例核验为验收路径，WebUI 可按需要提供运维说明入口。 [F14 运维文档](../../deploy/README.md)

## 首版验收点

1. 登录页、展开与折叠侧栏均能识别齿轮 Logo。保存后登录页和已登录页面显示新名称，重启与备份恢复后设置仍可读。已有个人主题保留其优先级。
2. 普通用户和厂区范围不符的账号调用管理接口得到拒绝。并发保存应提示重新加载。成功更新可按操作者、目标和请求追踪到审计记录。
3. 排程默认显示厂区当前周，核对跨月、跨年和跨午夜班次。切换日／周后能找到同一计划并打开详情，自动排程按确认表单日期执行。
4. 在非首页验证精确和模糊搜索、键盘导航、清空与空结果，并确认搜索结果符合当前账号权限。折叠前后核对正文宽度与当前菜单高亮，并在 390 像素宽度及浅深主题下检查导航和搜索。
5. 在 Docker 同源入口回归登录、系统设置、工作台和排程，核对厂区时区与生产日口径，并确认设置故障时页面可用默认品牌信息。

## 实现与运维

- 「组织与系统」下的「系统设置」包含「站点外观」「排程」「系统信息」。外观默认使用原站点名称与副标题，支持空副标题。浏览器已有主题记录优先，首次打开且无个人设置时采用站点默认主题。默认主题可选「跟随系统」，按访问者操作系统的浅色／深色偏好解析，系统偏好变化时已打开的页面同步切换；预览按当前系统偏好显示。
- 第 14 条迁移新增单实例外观和按厂区保存的排程配置。F1 分别控制管理读取及两项写入，F12 业务审计记录站点外观和排程设置的前后值。服务就绪状态使用现有探针，检查时间显示最近一次检查完成时刻。
- 本地升级和最小权限命令见 [数据库实施说明](06-database-implementation.md)。正式交付通过 F14 备份和恢复命令保存站点与排程配置。

## 验收记录

- 本地开发库已备份并升级，既有账号和生产事实计数一致。应用以原运行账号重新就绪。全量幂等 SQL 在隔离空库连续执行两次。
- 17 项数据库测试与 108 项 API 测试通过。Docker 同源入口的 Chrome 全流程通过，覆盖周历跨年与日视图拖拽、设置并发冲突、个人主题优先、设置接口故障时的默认品牌和 390 像素导航。
- 独立 Docker 实例的断库恢复、API 重建及备份恢复通过。恢复后的站点外观和厂区排程设置与备份前一致，原会话可继续读取业务和设置数据。
