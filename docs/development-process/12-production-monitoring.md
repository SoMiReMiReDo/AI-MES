# MESagent 生产监控开发文档

2026-11-19｜厂区看板与班次监控

## 参考与确认

OpenMES v0.25.0 的通用设置页提供语言、时区和币种。实际监控入口在左侧导航。厂区看板用设备卡片显示运行状态、停机时长、当前生产和班次表现，支持全屏展示及点击设备进入班次监控。班次监控可切换设备与班次、回到当前班、查看生产速率和设备状态时间轴，并在分析页下钻停机原因、时间损失及质量。参考页另提供原因补录及转维修。 [通用设置](http://localhost:8080/settings/system?tab=general) · [厂区看板](http://localhost:8080/admin/shift-board) · [班次监控](http://localhost:8080/admin/shift-monitor)

用户确认两页均开发。监控页只读，停机明细跳转现有「设备与资源」处理。

## 页面与指标

| 页面 | 首版功能 |
| --- | --- |
| 厂区看板 | 入口在「生产运营」。显示当前厂区的启用设备、按状态汇总、区域、设备编号与名称筛选、停机原因及持续时间、当前 Lot／工单、当前班与 OEE 分项。点击整张卡进入班次监控。大屏模式收起应用导航，并提供退出入口。 |
| 班次监控 | 支持切换设备、上一班／下一班／回到当前班。按所选班次显示设备状态、实际 Run、晶圆过站速率、实际通过及失败片数，展示班次 OEE、时间损失和停机原因。点击停机记录或 Run 跳到来源页。 |

- 班次以厂区时区、设备产线和启用日历为准，跨午夜班次归开始日期。重叠时优先采用产线班次，再选最近开始的班次。同开始时刻合并为一个导航入口。无适用班次时展示设备现状并允许切至上一班或下一班。
- 状态时间轴取已记录的设备有效状态，空白区间显示「无状态记录」。实际 Run 与状态分两行，设备停机期间仍开着的 Run 仍可见。未来区间显示为未发生。
- 速率按班次开始滚动分桶，每 60 分钟统计实际过站结果，当前桶按已过分钟计算。产速参照来自 F10 的设备理想秒／片。
- OEE 沿用 F10 班次报表的运行覆盖、完整逐片结果与跨班比例分摊口径。实际过站数使用逐片结果时间，因此与 OEE 分摊片数可能不同。缺少班次、理想产速或完整结果时按数据口径显示空值。失败片与报废有独立业务含义。
- 页面采用 MESagent 浅深主题。状态使用文字及颜色，卡片和来源链接支持键盘操作，窄屏可纵向浏览。

## API 与数据边界

- `GET /api/v1/workbench/plant-board` 支持 `areaId`、`state`、`q`、`page` 和 `pageSize`。状态汇总随区域和关键词变化。停机、维护设备优先排序，同状态按设备编号和 ID 稳定排序。
- `GET /api/v1/workbench/shift-monitor/{equipmentId}`，可传带时区的 `startsAt` 精确定位班次。返回设备、班次前后导航、实际状态与 Run 区间、停机履历、速率和 OEE。
- 两个 API 都要求当前厂区范围及 `equipment.read`。有 `execution.read` 才返回实际批次、工单、Run、过站数量和 OEE。可下钻设备须在当前厂区启用。API 使用现有一致性快照。
- 复用 F5、F7、F10 已有表和 SignalR 刷新通知。信号仅触发重新查询，连接异常时每 30 秒轮询。实时累计按服务端快照时间显示，页面标记数据更新时间和刷新失败。无需迁移。

## 验收

- 验证运行、停机、维护和空数据，核对筛选、状态统计、大屏与设备卡片下钻。
- 核对跨午夜班次、设备切换、上下班切换、当前班与历史班、时间轴和设备停机来源链接。
- 以真实 Run 核对晶圆数量、速率、缺失产速和班次 OEE；使用仅设备读权限及无厂区权限账号核对响应字段和 API 拒绝。
- 核对浅深主题、桌面和 390 像素页面，以及实时通知和降级刷新。

本地验证已通过 17 项数据库测试、110 项 API 测试和 Chrome 全流程。浏览器覆盖大屏、键盘打开设备卡片、班次切换、指定停机记录下钻、浅深主题、390 像素布局及阻断 SignalR 后的轮询。已在原开发实例核对实际设备、运行批次和停机记录。
