## 2. 页面与指标

### 工单履历

- 列表默认最近 30 天，按工单号、产品／修订和履历事件筛选。每个工单一行。日期锚点优先取可核验的关闭或取消事件时间，其次取达到计划量的实际完成时间。达到计划量但仍处于 `Released` 的工单显示「已达计划」及原状态。缺少终态时间来源的历史单以工单号可查，标记「历史时间缺失」，日期汇总排除该行。
- `WorkOrderSnapshot` 提供下达基线。`WaferRelease` 和 `WaferCompletion` 提供实际投放与路线终点数量，复用 F3 进度核验。计划量、投放、完工和报废按来源分别显示。关闭或取消时间取本厂工单同一对象的 F3 `close` / `cancel` 记录。`CompletedAt` 表示可信实绩达到计划量的时刻；遇到历史缺口，实绩与达成状态均标缺。拆合批、重复过站和合批耗尽均不额外增加完工片数。
- 按期达成率为在厂区本地交期当日或之前达到计划量的工单数 ÷ 有交期且已核验达到计划量的工单数。展示分母，未达计划的关闭单单列。工单生产历时取首次实际投放到达到计划量的时间差，有效样本才参与平均。这项指标与设备 Run 时长分别呈现。
- 详情提供计划基线、完成与终态时间、关联 Lot 和授权证据链接。列表摘要与导出使用同一筛选条件，覆盖全部符合条件的已授权记录。 [F3 查询与终态](../../src/MESagent.Infrastructure/ProductProcessVersionManagement/Planning.cs) · [进度核验](../../src/MESagent.Infrastructure/LotWaferCarrierGenealogy/ProductionProgress.cs) · [现有追溯](../feature-development/traceability-impact-analysis.md)

### 报废分析

- 默认最近 30 天，按厂区日期、产品、工序、原因筛选，有权限时可选设备。粒度为有效 `WaferDisposition(Scrap)`，按 `OccurredAt` 与处置时的 Lot 统计，按 `ScrapEntryId` 计算单据数，按稳定原因 ID 聚合片数。Pareto 按片数降序、原因编码与 ID 稳定排序，累计占比基于当前筛选总片数。原因行下钻到逐片处置，再打开质量和追溯来源。
- 工序取受校验的实际 Run 或报废单关联步骤，设备取处置所关联的有效 Run。缺少关联时在未指定该维度的总量内单列「归属未知」。失败过站、检验失败和 Hold 分别保留原含义。报废上下文表示关联工序或设备，原因分析可以据此定位记录。
- 建议在厂区／产品维度显示「同期已结案片报废占比」＝期间报废片数 ÷（期间终点完工片数＋期间报废片数）。该指标按事件日期反映同期结案构成，分母为零或来源不足时显示空值。工序／设备筛选下先显示报废片数；分设备报废率与同投放批次良率等待可匹配的分母和归因规则。Die 级良率另行定义。 [报废事实](../../src/MESagent.Infrastructure/QualityExceptionDisposition/Disposition.cs) · [现有历史统计](../../src/MESagent.Infrastructure/WorkbenchDashboardsAlertsScheduling/History.cs)

### 设备 OEE

- 默认最近 7 天。按区域、产线、设备和班次筛选，首版提供按日趋势、设备对比和设备×班次明细。明细显示计划时长、实际 Run 覆盖、登记停机、理想秒／片、分摊加工与失败片次、A/P/Q 和 OEE。点击班次进入现有班次监控，停机记录沿现有入口打开。
- 延用 F10 单班规则。A＝实际 Run 时间并集 ÷ 班次计划时长；P＝理想加工时长 ÷ 实际 Run 覆盖时长；Q＝通过片次 ÷（通过片次＋失败片次）；OEE＝A×P×Q。当前班截到查询快照，跨午夜按班次开始日，完成 Run 按时间重叠比例分摊逐片结果。登记停机独立呈现，P 保留原始值。缺班次、理想产速或完整逐片结果时，受影响指标显示空值并列出原因。历史班次沿现有日历和设备归属重算，注明口径。
- 周期汇总从原始时长与片次分别合成 A/P/Q，再相乘。理想加工时长按各设备和班次各自的生效产速折算。同一设备的重叠班次、缺少产速或结果等情形须明确有效覆盖；重叠窗口归属未明确时仅展示逐班值，汇总留空并给出原因。有 Run 但缺结果的窗口不得通过忽略该窗口生成完整的 P/Q。跨设备综合、周／月趋势和 PDF 后置。 [现有 OEE 计算](../../src/MESagent.Infrastructure/WorkbenchDashboardsAlertsScheduling/Shifts.cs) · [班次监控入口](../../web/src/shiftMonitor.tsx)

### 生产成本

- 首版入口显示成本准备状态及来源说明。F3/F5 可提供完工片数，F8-01 可追溯硅片来料。实际耗用、价格快照、人工计价及附加费用尚无可用核算口径。缺项显示「待接入」，金额、总成本和单片成本留空。禁止从来料登记量或设备 Run 时长推算实际成本。
- 开启核算前，由业务确认财务／ERP 权威源、F8 实际耗用与单位转换、消耗时点的计价与币种、人工分摊和费用归集、月结与更正机制。后续区分实际成本、标准成本估算和缺数。单片成本按同口径成本 ÷ 已核验完工片数，产量为零时留空。多币种须有明确折算依据才合计。成本明细与导出须单独授权。 [现有 F8-01 范围](../feature-development/material-consumption-inventory.md) · [现有功能边界](07-fab-function-catalog.md)

## 3. 实现与权限

建议在既有模块化单体中增加类型化生产分析查询，复用 F3/F6/F9/F10 的数据事实与计算入口。列表、汇总与下钻在各自请求内使用现有一致性快照；WebUI 仅做展示。首版使用现有表按条件查询，量测后再决定索引或预聚合。计划仅新增查询与导出审计，不新增生产事实或成本账本。

| 建议 API 前缀 `/api/v1/analytics` | 查询内容 | 现有权限门禁及扩展 |
| --- | --- | --- |
| `GET /work-orders`、`GET /work-orders/{id}` | 汇总、分页、工单履历详情 | `planning.work-orders.read`；Lot、Wafer、Run、质量等明细和链接分别沿用来源读权限。报废栏按 `quality.read` 限制。 |
| `GET /scrap`、`GET /scrap/records` | 原因、日期和工序／设备分布，逐片分页 | `quality.read`；占比同时要求 `production.lots.read`；设备筛选及设备信息要求 `equipment.read`。 |
| `GET /oee`、`GET /oee/shifts` | 设备对比、趋势和班次明细 | `equipment.read` 与 `execution.read`。班次、Run、停机来源入口继续自行校验。 |
| `GET /cost-readiness` | 来源和待接入项 | `planning.work-orders.read`；首版状态为通用信息。实际金额上线时另设财务读权限。 |

- 厂区由已授权会话决定。聚合、可选筛选项、明细、引用和导出都先按厂区与来源权限过滤。受限筛选参数由服务端拒绝，受限字段与链接在服务端省略。工单关闭／取消时间可由工单应用服务投影为履历字段，原始审计正文沿 F12 权限读取。
- `from`、`to` 使用厂区本地日期并包含首尾两日，服务端转换为 UTC 半开区间。筛选保存在 URL，返回列表后保留原条件。建议明细默认 20 条、最多 100 条。工单与报废自定义窗口暂拟最多 90 天，OEE 暂拟最多 31 天并做数据量验证。无记录、数值为零、缺数据和权限受限应有可区分的表现。
- 首版建议支持工单 CSV，后续按需求增加报废和 OEE 导出。工单导出复用同一查询条件与字段授权，使用服务端行数上限和公式注入保护，记录操作者、厂区、生成时间、筛选、行数及追踪 ID。 [共享应用入口](../../src/MESagent.Infrastructure/OrganizationIdentityAccessControl/OrganizationIdentityAccessControlBackend.cs) · [F12 审计](../feature-development/application-audit-reliability.md)

## 4. F13 Agent 接入预留

- WebUI 与后续 F13 工具调用同一组 Application 查询。模型只传白名单筛选、对象 ID、日期与页码，服务端从会话绑定用户和厂区。各次工具调用及来源打开重新授权，遵循同一分页、超时与范围限制。工具只读，模型输出无法直接更新 MES 或控制设备。
- 为每个查询返回统一证据元数据。建议包括 `asOf`、`timezone`、规范化筛选、`metricVersion`、计量单位、分子／分母及结构化缺数原因。证据含 `kind`、稳定记录 ID、发生时间和可打开的应用内链接，按权限返回并有数量上限。确定筛选后可用同一 URL 复查。`asOf` 表示读取快照时间，历史范围重跑仍可能随补录和配置变化。F13 工具审计可沿用 F12 追踪 ID，记录查询类型、范围、口径版本和返回数量。
- 优先预留三类问题的证据路径。工单为何未达计划可引用终点完工、报废和授权异常记录；某周报废集中在哪些原因可引用 Pareto 与处置单；某设备某班 OEE 下降可引用 A/P/Q 和登记停机记录，因果判断保留为解释。欠缺成本来源时只回答数据准备状态和缺项。F13 的模型、对话 UI、工具注册及评测实现留待 Agent 阶段。 [F13 功能范围](07-fab-function-catalog.md#f13-agentworkbench-agent-工作台)

## 5. 实施顺序与验收

建议先共用查询参数、权限和证据契约，再交付工单履历与报废分析，随后接通 OEE 趋势与成本准备页。试点演示使用 `DEMO-FAB-` 现有样本；缺少的日期边界与并发情形在隔离库补夹具。 [已有演示数据](10-fab-showcase-data.md)

| 验收对象 | 必测场景 |
| --- | --- |
| 工单 | 已达计划仍下达、提前或逾期、无交期、无产出关闭、取消和缺历史时间。存在拆合批与重复过站仍按唯一终点片计数。汇总、分页和 CSV 对照同一筛选。 |
| 报废 | 一单多片、跨日期、同名不同原因编码、无 Run 设备、部分报废和失败后恢复。Pareto 与逐片明细数对账，零分母显示空值。 |
| OEE | 与 F10 同设备同班逐项一致；测试跨午夜、在班截断、跨班分摊、重叠窗口、缺产速和未完成 Run。不同计划时长的多班汇总用原始量复核。 |
| 成本 | 只有来料登记或完工事实时，显示相应准备状态，金额留空。 |
| 权限及 Agent 契约 | 无厂区授权、仅有部分来源权限、越权 ID 与撤权后的证据链接。核对列表、汇总、导出的隔离。在固定时钟及相同事实、用户和筛选下，应用查询与 HTTP 返回相同指标和可引用证据。 |

待确认事项包括成本接入与财务口径、设备级报废率分母、报告时段上限及扩展导出优先级。首版实施与演示说明见下节。

## 6. 首版交付与演示数据

WebUI 入口为「生产分析」，包括工单履历、报废分析、设备 OEE 和生产成本。OEE 按设备展示期间 A/P/Q、设备对比及可切换指标的日趋势。设备对比可切换焦点，按日图支持键盘选择日期。班次表提供计划、Run、停机、分摊后的片次与同一设备同一班次的监控链接，保留性能率原始值。

- 工单、报废默认 30 天，分别最多 90 天。OEE 默认 7 天，最多 31 天。分页默认 20 条，最大 100 条。
- CSV 使用 `POST /api/v1/analytics/work-orders/export` 下载，上限 10,000 行，与工单列表共用筛选和权限。导出具有防伪校验、公式注入保护与同事务审计。
- 同期结案占比只在厂区／产品范围计算。质量、批次、晶圆、设备及 Run 来源链接独立校验。成本显示来源准备状态，金额留空。
- 现有模式无需迁移。WebUI 与后续 Agent 共用应用查询。元数据包含快照时间、厂区时区、筛选参数、计量单位、指标版本、缺数代码及最多 20 条证据引用。班次汇总直接使用历时和片次分子、分母。

17 项数据库测试和 113 项 API 测试通过。Chrome 在隔离数据库中核对四页、CSV 与查询对账、报废原因下钻、F10 班次链接、跨班片次分摊和原始分子分母加权，以及 390 像素浅深主题。

### 已装载的本地样本

本地开发库 `mesagent` 新增 `DEMO-AN-` 样本，班次开始日为 **2026-10-22～2026-11-18**。两条演示线、六台设备、白／夜班对应 458 张工单、448 批、9,856 片晶圆、1,344 次 Run、84 张报废单和 224 条停机记录。逐片结案对账为 **9,689 完工＋167 报废**。部分夜班记录延伸至 11 月 19 日。批量样本复用既有演示工艺与指导书，部分合成 Run 日期早于模板的系统发布登记。工艺发布合规的验证需要独立的时序样本。

| 可复查的线索 | 查询入口 |
| --- | --- |
| 逾期、无交期、低于计划关闭、取消和历史终态缺失 | 工单履历选择 10 月 22 日～11 月 19 日，检索 `DEMO-AN`。用 `DEMO-AN-TERMINAL-10` 查缺历史终态时间的工单。 |
| 多片报废、同名不同编码及缺设备归属 | 报废分析选择同一日期范围，核对 Pareto、每日数和逐片处置。 |
| 性能率变化、跨班片次分摊和产速缺档 | OEE 选择「分析演示区」。用 `DEMO-AN-A2` 对比 11 月 14～16 日与其他日期，用 `DEMO-AN-A3` 看白夜班分摊，用 `DEMO-AN-B3` 查看 10 月 22～25 日缺产速。 |
